# LG 트윈스 팬사이트 — 3단계 응원 문화 페이지 설계

작성일: 2026-09-28

## 1. 목표

로드맵 3단계인 **응원가/응원 문화 페이지(`/cheer`)**를 만든다. 팀 응원가, 선수별 응원가, 응원단 소개, 응원 도구, 응원 매너를 한 페이지에 담는다.

### 전체 로드맵에서의 위치

0. 기반 세팅 + 메인 페이지 (완료)
1. 역사/우승 기록 (완료)
2. 선수단 소개 (완료)
3. **응원가/응원 문화 (이 문서)**
4. 경기 일정/결과
5. 순위/기록
6. 뉴스/게시판 커뮤니티

## 2. 확정된 결정

| 항목 | 결정 |
|------|------|
| 콘텐츠 범위 | 팀 응원가, 선수별 응원가, 응원단(응원단장·부응원단장·장내아나운서·치어리더), 응원 도구, 응원 매너 — 5개 섹션 |

## 3. 검증된 데이터

### 팀 응원가 (13곡, 제목만)

2020 일어나라 LG, 강해져라, 깃발응원가, 라인업 송 - 유모레스크, 무적 LG 끝까지 트윈스, 무적의 LG, 사랑하는 LG, 사랑한다 LG, 승리를 위하여, 승리의 포효, 엘팬의 북소리, GO TWINS, LG의 승리 위해

### 선수 응원가 (15명, 17곡 — 박해민·오스틴 딘은 2곡)

구본혁, 김주성, 문성주, 문정빈, 박동원, 박해민(2곡), 송찬의, 신민재, 오스틴 딘(2곡), 이영빈, 이재원, 이주헌, 천성호, 최원영, 홍창기

각 항목은 "선수 이름 + 응원가 제목"만 있고, 가사·멜로디 정보는 없다. 곡 제목은 원본에 `"{이름} 응원가"` 형태로 표기돼 있어(예: `"구본혁 응원가"`), 실제 제목 텍스트를 그대로 옮긴다.

### 응원단 (16명)

- 응원단장: 이윤승
- 부응원단장: 김태리, 최서용
- 장내아나운서: 황건하
- 치어리더(12명): 차영현, 임혜진, 진수화, 우혜준, 박예은, 신서윤, 고예지, 김태희, 서여진, 장로나, 양효주, 이서우

사진은 쓰지 않는다(기존 규칙 유지). 이름과 역할만 표기한다.

## 4. 데이터 모델

```ts
// src/lib/types.ts
export type TeamCheerSong = { title: string };
export type PlayerCheerSong = { player: string; title: string };
export type CheerStaffRole = "응원단장" | "부응원단장" | "장내아나운서" | "치어리더";
export type CheerStaffMember = { name: string; role: CheerStaffRole };
```

- `src/data/cheer.ts`에 `TEAM_CHEER_SONGS`(13), `PLAYER_CHEER_SONGS`(17), `CHEER_STAFF`(16)를 담는다.
- `src/lib/cheer.ts`에 `getTeamCheerSongs()`, `getPlayerCheerSongs()`, `getCheerStaff()` 세 함수를 둔다. 이 데이터는 기존 `Player`(선수단) 타입과 독립적이다 — 응원단원은 선수가 아니고, `PlayerCheerSong.player`는 선수단 데이터와 대조 검증하지 않는 단순 이름 문자열이다.

## 5. 페이지 구조

```
src/app/cheer/
  page.tsx / page.module.css
src/components/cheer/
  TeamSongList.tsx / .module.css       # 팀 응원가 13개
  PlayerSongList.tsx / .module.css      # 선수 응원가, 선수별로 묶어서 표시(2곡인 선수는 나란히)
  CheerStaffList.tsx / .module.css      # 응원단장/부응원단장/장내아나운서/치어리더, 역할별 그룹
  CheerTools.tsx / .module.css          # 응원 도구 설명 (정적 콘텐츠)
  CheerManners.tsx / .module.css        # 응원 매너 (정적 콘텐츠)
```

- `/cheer` 하나의 페이지에서 5개 컴포넌트를 순서대로 조립: 팀 응원가 → 선수 응원가 → 응원단 → 응원 도구 → 응원 매너.
- 각 섹션은 기존 `SectionTitle` UI 컴포넌트(`<h2>`)를 재사용한다. 페이지 최상단에는 직접 `<h1>` 하나("응원 문화")를 둔다(1·2단계와 같은 이유 — 독립 페이지는 자체 `<h1>`이 필요).
- 페이지 상단에 5개 섹션으로 이동하는 간단한 앵커 링크 목록을 둔다(필터 컴포넌트가 아니라 단순 텍스트 링크).
- 전부 정적 데이터라 필터·탭 같은 상태 관리가 필요 없다. 각 컴포넌트는 props로 받은 배열을 그대로 렌더링하는 프레젠테이션 컴포넌트다.
- **응원 도구** 섹션(정적 텍스트, 검증 불필요): 막대풍선/스틱, 대형 카드(플래카드), 유니폼·굿즈 착용 문화를 3~4개 카드로 소개한다.
- **응원 매너** 섹션(정적 텍스트, 검증 불필요): 공격 이닝에 응원하고 수비 이닝엔 자제하기, 파울볼 주의, 다른 팀 팬 배려 등 KBO 통용 에티켓을 리스트로 소개한다.

## 6. 접근성, 에러 처리, 테스트

- 앵커 링크는 일반 `<a href="#section-id">`로 구현하고, 각 섹션에 대응하는 `id`를 부여한다.
- `getTeamCheerSongs()`/`getPlayerCheerSongs()`/`getCheerStaff()` 실패 시 `/cheer` 페이지는 크래시 대신 "응원 정보를 불러오지 못했어요" 안내 문구를 보여준다(`safe()` 재사용, 세 함수 중 하나라도 실패하면 페이지 전체를 이 안내로 대체 — 정적 데이터라 부분 실패보다 전체 실패로 처리하는 것이 단순하고 충분하다).
- 테스트: `lib/cheer.ts`의 세 함수(개수 검증: 팀 13, 선수 응원가 17, 응원단 16, 응원단 역할별 인원수 검증), 각 컴포넌트가 주어진 배열을 올바르게 렌더링하는지(빈 배열일 때 처리 포함).
- 메타데이터: title "응원 문화", description은 응원가·응원 문화 소개 한 줄.

## 7. 범위 밖 (3단계에서 하지 않는 것)

- 선수·팀 응원가 가사 전문, 멜로디/악보
- 등장곡(입장곡) 66개 (투수 31 + 야수 35)
- 응원단원 사진, 생년월일 등 프로필 상세
- 응원가 음원/영상 재생 기능
- 선수단 데이터(`Player`)와의 상호 참조(예: 선수 응원가 클릭 시 `/players/[name]`으로 연결하는 것 등)
